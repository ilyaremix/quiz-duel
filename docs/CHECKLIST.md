# Ручная проверка перед сдачей

По таблице крайних случаев из [README](../README.md#крайние-случаи), на настоящих устройствах: iPhone, Android и Telegram Desktop.
Отмечайте `[x]` в колонке устройства, где проверили. Если что-то не так - пишите номер строки и что увидели.

## Подготовка

- **Аккаунт А** - на iPhone. **Аккаунт Б** - на Android. Это два разных аккаунта Telegram.
- **Telegram Desktop** - войти в аккаунт А (для строки «два устройства») и добавить третий аккаунт В
  (Настройки → «Добавить аккаунт»; для строки «третий открыл ссылку»). Можно попросить друга вместо аккаунта В.
- На всех устройствах обновить Telegram. Открыть [@q_battle_bot](https://t.me/q_battle_bot) → «Старт» → «Играть».
- Новый аккаунт сначала видит 3 слайда и две галочки (соглашение и политика) - отметить обе → «Начать играть».
- «Сделать дуэль» ниже = Главная → «Создать дуэль» → любая категория → «Создать дуэль» → «Пригласить» → отправить карточку
  в личку второму аккаунту. «Зайти» = нажать «Принять» на карточке.

## Только автотесты

Руками это не проверить, поэтому - только автотесты (где они - в таблице README): двое открыли ссылку в одну и ту же
миллисекунду, ответ через 300 мс после конца таймера, поддельный initData, перезапуск сервера посреди партии
(можно и руками: перезапустить контейнер `server` на сервере посреди вопроса - партия должна продолжиться),
подмена user_id в запросе согласия, новая версия документов.
